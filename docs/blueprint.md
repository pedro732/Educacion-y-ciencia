# **App Name**: Safari Navigator

## Core Features:

- Navigation Bar: Implement a navigation bar with 'Inicio,' 'Blog,' 'Zoologia,' and 'Volver' buttons.
- Image Carousel: Fetch and display animal images from the Pixabay API in a carousel format. API key management handled on server.
- Carousel Controls: Enable navigation between carousel images.

## Style Guidelines:

- Primary color: Deep orange (#B85A0A), reminiscent of the colors of a savannah sunset.
- Background color: Soft beige (#F2E9DC), evoking a sense of natural paper or canvas.
- Accent color: Muted teal (#5A8A75), for interactive elements and calls to action; teal is also evocative of the African wild.
- Body and headline font: 'Alegreya', a humanist serif with an elegant, intellectual, contemporary feel.
- Use animal icons relating to the topic of animals in the zoology and blog sections.
- Employ subtle transitions when navigating between images in the carousel and when switching between sections.
- Layout should have white spaces and margins to give the website's sections better spacing.
